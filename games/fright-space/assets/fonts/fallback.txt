# The fonts the HUD falls back to for a character its atlas (dejavu-sans-48) lacks (`src/script.rs`,
# roadmap H7), in the order they are tried: a file beside this list, then the code points (hex, a
# range or one) it is opened for. A font is read the first time a line needs one of its ranges - a
# game that never shows Chinese never reads the CJK font - and `WORLD_FONTS` names another list.
#
# A font may also have a source, `url=` and `sha256=` (H10, `src/fonts.rs`; a line that starts with a
# space goes on with the font above, so they can have lines of their own): then it need not be on disk. It is looked for beside this list, then in the user's font cache (`WORLD_FONT_CACHE`,
# by default %LOCALAPPDATA%\densarender\fonts), and one in neither is downloaded the first time a line
# needs it - on a thread of its own, to <font>.part, kept only if its SHA-256 is the one given -
# beside this list if this directory takes a file, else in the user's cache. `densarender fonts fetch`
# gets them ahead of time, and `densarender package` puts in the ones a game's strings need. The CJK
# font (16.4 MB) is not in the repository for this reason; the Arabic and Hebrew ones are small and are.
#
